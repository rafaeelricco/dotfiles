# Build

Load `bar.md`. Run in order. No menu of motion options.

1. Gate — fail → say so, offer the non-motion alt, stop.
2. Purpose — name one bar word. Can't → stop.
3. Tool — first fit in bar. Component (toast/drawer/⌘K/dropdown) → hand off to `lib`.
4. Properties — bar. `clip-path` ok; `height` only accordion.
5. Curve / duration / spring — bar. Prefer repo tokens.
6. Interrupt + exit — transitions if rapid; springs if gesture; same path out; hold 2s / snap 200ms.
7. A11y ships in the same edit.

Matching recipe → start from `recipes.md`.

Then write the code. Recap in three lines: gate, ingredients, feel-check.
