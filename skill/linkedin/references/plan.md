# 21-day plan

A schedule, not doctrine. This file names areas and sequences them; it never restates their
rules. When a step says run an area, that is a fresh route into this skill on a later turn,
loading that one reference then.

Load this file alone. Do not pre-load the area files it names.

Every step is marked **[artifact]** — this skill produces it — or **[action]** — only the
user can do it. Most of weeks 2 and 3 is action. That is the point: the profile is finished
early and the rest is execution.

## Week 1 — build the asset

Front-loaded on purpose. The profile has to be finished before traffic is worth sending to
it.

| Day | Step                                                    | Kind                  |
| --- | ------------------------------------------------------- | --------------------- |
| 1   | Record the starting SSI and all four pillar scores      | [action]              |
| 1-2 | Run `positioning` — focus, then the ranked keyword list | [artifact]            |
| 3   | Run `headline`                                          | [artifact]            |
| 3-4 | Run `about`                                             | [artifact]            |
| 4-5 | Run `experience`                                        | [artifact]            |
| 5   | Run `sections`, then fill the fields                    | [artifact] + [action] |
| 6   | Run `visuals`; take or choose the photo, set the cover  | [artifact] + [action] |
| 6   | Request 5 recommendations, sending one first            | [action]              |
| 7   | Run `content`; pick the fixed publishing days           | [artifact]            |

Done when: the profile passes the 5-second test, every section is filled, and the keyword
list exists in writing.

## Week 2 — reach

The daily rhythm starts and does not stop. Nothing here is a one-off.

| Cadence | Step                                                     | Kind                  |
| ------- | -------------------------------------------------------- | --------------------- |
| Daily   | 5-10 substantive comments in the field                   | [action]              |
| Daily   | 10 connection requests to recruiters, peers, and leaders | [action]              |
| Daily   | Message every connection that accepted — run `outreach`  | [artifact] + [action] |
| 3×/week | Publish on the fixed days — run `content` for drafts     | [artifact] + [action] |
| Once    | List 20 target companies; connect inside each            | [action]              |
| Once    | Join active groups in the field and comment in them      | [action]              |
| Day 14  | Re-read the SSI score and all four pillars               | [action]              |

Done when: connection count is climbing toward 1500 in-field and every accepted connection
has been messaged.

## Week 3 — convert and measure

| Cadence | Step                                                          | Kind                  |
| ------- | ------------------------------------------------------------- | --------------------- |
| Daily   | Hold the week-2 rhythm unchanged                              | [action]              |
| Once    | Follow up with everyone who did not reply — run `outreach`    | [artifact] + [action] |
| Day 18  | Run `ssi` against the metrics; check the searching job titles | [artifact]            |
| Day 21  | Record the final score; compare against day 1                 | [action]              |

Done when: the target job title appears in search appearances and the weekly trend is up.

## After day 21

The score falls without maintenance. The sustaining rhythm is the week-2 daily block, minus
the one-off setup: comments, connections, messages to everyone who accepts, and the fixed
publishing days.

If the target job title never appeared in search appearances, the problem is upstream of
effort. Re-run `positioning` — the keywords are wrong, and no amount of activity fixes that.

## Intensity

The cadence above assumes a full-time search. To run it slower, scale the daily numbers
down and hold the sequence and the fixed publishing days — those are what the algorithm
reads. Do not stretch week 1; a half-finished profile earns nothing from weeks 2 and 3.
