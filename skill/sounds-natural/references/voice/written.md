# Written examples

The user's own drafts (Sep 2026), then a version that follows profile.md. Each Polished line uses only the facts in
its Raw line; `[brackets]` mark a detail the user has to supply.

## Recruiter email: intro

Raw: "I'm senior software engineer with 5 years of experience most of it working with distributed, event-sourced
system. I've been working last year on products using AI workflows using Python (LangChain, LangGraph,
Transformers, RAG), TypeScript (Express, MongoDB, PostgreSQL) and React (Vite, TailwindCSS, Shadcn/UI) for this."
Polished: "I'm a senior software engineer with five years of experience, most of it on distributed, event-sourced
systems. For the last year I've been building AI products. My stack there is Python with LangChain, LangGraph,
Transformers, and RAG; TypeScript with Express, MongoDB, and PostgreSQL; and React with Vite, Tailwind CSS, and
shadcn/ui."
Rule: three-step intro; the stack moves to its own sentence.

## LinkedIn post: a challenge

Raw: "Talking about implementation, one of the biggest challenges we faced was: estate agencies are techinically
illiterate, they couldn't give use API access to their data and they also doesn't have engineers. The solution I
propose was a pipeline that crawls the agency's own website and turn it into a structured property catalogue (to
achieve the same structure if we're consuming an API basically), then the AI agent answers using RAG to consult
the informations (apply filters, search by specific neighbors and book property viewing) and perform actions that
was needed someone involved before."
Polished: "Talking about implementation, one of the biggest challenges we faced was: the estate agencies weren't
technical. They couldn't give us API access to their data, and they didn't have engineers. The solution I
proposed was a pipeline that crawls the agency's own website and turns it into a structured property catalogue.
That achieves the same structure as if we were consuming an API. Then the AI agent answers using RAG to consult
the information, apply filters, search by specific neighborhoods, and book a property viewing. It now performs
actions that used to need someone involved."
Rule: the colon setup and "we" stay; the blunt line about the agencies not being technical loses its harsh word,
"neighbors" becomes "neighborhoods", and the run-on splits into sentences in the same order.

## Disagreeing

Raw: "I disagree. I can see what you're seeing and I understand why do you see things in that way, but I would
like to mention x and y to remember we must do this for the good of the project. My position about that is X and
Y."
Polished: "I disagree. I can see what you're seeing, and I understand why you see things that way. But I'd like
to mention [x] and [y], to remind us that we must do this for the good of the project. My position on that is
[X and Y]."
Rule: the disagree-then-acknowledge-then-shared-goal order and "we must" stay; the unspecified points become
`[x]`, `[y]`, and `[X and Y]` placeholders.
