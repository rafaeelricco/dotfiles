# Rowland (2014): a meta-analysis of the testing effect

- Citation: Rowland, C. A. (2014). The effect of testing versus restudy on retention: A meta-analytic review of the testing effect. _Psychological Bulletin, 140_(6), 1432-1463.
- Original: https://doi.org/10.1037/a0037559 (paywalled at APA)
- Read: abstract only, from the Europe PMC record of PubMed ID 25150680 (https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:25150680%20AND%20SRC:MED&resultType=core). The abstract reports no numbers, so this note has none.

## Argument

Rowland pooled studies that compared taking a test on studied material with restudying it. The outcome was later retention. The review also asked which theories of the testing effect fit the pattern of results. It looked at test type, comparing initial recall tests with recognition tests. It also checked whether the data supported accounts built on semantic elaboration.

## Findings

- Testing beat restudy for retention. The abstract calls a test a potent learning event.
- Initial recall tests gave larger benefits than recognition tests. The author reads this as support for effortful processing as a source of the effect.
- Support for the semantic elaboration account was limited, so the author says other mechanisms need to be considered.
- The author suggests future accounts should include episodic and context-based effects of retrieval. The abstract also calls the bifurcation model a viable framework for the pattern of results.

## Limits

Only the abstract was read. It gives no number of studies, sample sizes or effect sizes. So the size of the benefit, and any moderators beyond test type, are not covered here. The conclusions about mechanisms are the author's reading of the pooled data. The abstract itself says current theories give no cohesive account of the effect.
